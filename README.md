# Persian Spotify

Data mining project on Persian artists on Spotify: exploratory analysis, then supervised models for insight and prediction.

## Contents

| File | Description |
|---|---|
| `persianspotify.ipynb` | EDA, visualization, PCA, regression, and XGBoost classification |
| `Spotfiy_Persian_Artists.csv` | Artist / track features |
| `spotify_pred.csv` | Prediction outputs |
| `AUT Data Mining Spring 2023 Final Project Documnet.pdf` | Assignment write-up |

## Run

```bash
pip install numpy pandas matplotlib seaborn scikit-learn xgboost jupyter
jupyter notebook persianspotify.ipynb
```
